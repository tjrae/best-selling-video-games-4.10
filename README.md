
# Best-Selling Video Games

## Project Description
This project is a webpage that displays a table of some of the best-selling video games of all time.

## Features
- HTML table displaying video game information
- CSS styling for colors, borders, and spacing
- Alternating row colors
- Link to the original information source

## Files
- `index.html` - Contains the webpage structure and table
- `styles.css` - Controls the appearance of the webpage

## Technologies Used
- HTML5
- CSS3

## Data Source
Video game sales information was obtained from Wikipedia.
