# Best-Selling Video Games

A simple HTML and CSS table showing the best-selling video games, sales figures, and release dates from the provided CodingRooms project.

## Files

- `index.html` — webpage content and game data
- `styles.css` — table styling, CSS variables, and mobile width adjustments
- `.gitignore` — local files excluded from Git

## Run locally

Open `index.html` in any web browser. No installation required.

## Publish on GitHub Pages

1. Create a public repository named `best-selling-video-games`.
2. Upload these files to the root of the repository.
3. Under **Settings → Pages**, select **Deploy from a branch**.
4. Choose **main**, **/(root)**, and save.

Your site should then be at `https://YOUR-USERNAME.github.io/best-selling-video-games/`.

## Source

The original game figures and release dates were preserved from the uploaded assignment project, which links to [Wikipedia's list of best-selling video games](https://en.wikipedia.org/wiki/List_of_best-selling_video_games). They have not been independently updated or verified.
